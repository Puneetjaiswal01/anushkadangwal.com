# For My Pahadan ♡

A private, mobile-first interactive love letter built with HTML, CSS and JavaScript.

## Run locally
Open `index.html` in a browser.

## GitHub Pages
Upload the whole folder to a repository, then enable GitHub Pages from the repository's Settings → Pages → Deploy from branch → `main` / root.

## Optional soundtrack
Add your legally usable audio file as:

`assets/soundtrack.mp3`

The player will appear automatically. For copyrighted songs, use a lawful embed/link or audio file you have permission to use.


## Soundtrack
The music room includes links for Tere Sang Yaara, Aaj Bhi, Tere Ho Ke, Apna Bana Le, Hawayein, and O Maahi. The links open YouTube search results so the site does not redistribute copyrighted recordings.
