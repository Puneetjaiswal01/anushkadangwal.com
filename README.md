# For Anushka

A personal proposal site built with Next.js, React, Tailwind CSS and Framer Motion.

## Run locally
```bash
npm install
npm run dev
```

## Build static site
```bash
npm run build
```

The exported site is generated in `out/`.

## GitHub Pages
Deployment is handled by `.github/workflows/deploy.yml`. Set Pages source to GitHub Actions and use the custom domain `www.anushkadangwal.com`.
